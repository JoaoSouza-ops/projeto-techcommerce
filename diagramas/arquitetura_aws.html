Core Event Bus

🔀 Amazon EventBridge

Barramento customizado techcommerce-event-bus-prod. Filtra payloads JSON e roteia eventos de forma assíncrona e desacoplada.

• Rule 1: OrderCreated ➔ Validador
• Rule 2: OrderValidated / PaymentApproved ➔ Atualizador
• Rule 3: OrderStatusUpdated / Rejected ➔ Notificador
• Rule 4: Schedule Cron/Rate ➔ Relatórios
⚡ Desacoplamento Total (Loose Coupling) & Retry Automático + DLQ
AWS Lambda #1 • Python 3.12

λ validadorPedidos

Valida itens, disponibilidade de estoque e score antifraude. Emite OrderValidated ou OrderRejected ao EventBridge.

AWS Lambda #2 • Python 3.12

λ atualizadorStatus

Atualiza o status transacional do pedido no banco relacional gerenciado e publica OrderStatusUpdated.

AWS Lambda #3 • Python 3.12

λ notificadorEquipes

Formata alertas operacionais e publica nos tópicos do Amazon SNS para Logística e Atendimento.

AWS Lambda #4 • Python 3.12

λ geradorRelatoriosVendas

Acionada via Cron. Consulta a Read Replica do RDS, gera relatórios JSON/CSV e grava no Amazon S3.

Banco Gerenciado (Unidade 3)

🗄️ Amazon RDS (PostgreSQL Multi-AZ)

Instância Principal (Multi-AZ): Escrita transacional de pedidos com failover automático.
Read Replica: Leitura isolada para geração de relatórios sem onerar o checkout.

Mensageria Pub/Sub (Unidade 2)

📣 Amazon SNS (Notificações)

• Tópico Logística: Dispara separação de estoque e expedição (Webhook/E-mail).
• Tópico Atendimento: Notifica cliente e CRM sobre status ou rejeição antifraude.
